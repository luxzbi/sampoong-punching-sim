# 플랫슬래브 펀칭전단 · 연쇄붕괴 구조 시뮬레이터

**한국 현대건축의 발전과 안전의 그늘 — 일제강점기 근대 건축기술 도입에서 1995년 삼풍백화점 붕괴까지**
고등학교 한국사 수행평가 2차 탐구용 웹 기반 구조 시뮬레이션

> ### ⚠️ 교육용 단순화 모델
> 이 프로그램은 구조 개념을 이해하기 위한 **교육용 단순화 모델**이며,
> **실제 구조 안전진단이나 구조설계를 대체하지 않습니다.**
> 삼풍백화점 전체 구조를 정밀 복원한 유한요소해석이 아닙니다.
> 자세한 내용은 [`limitations.md`](./limitations.md)를 반드시 읽어 주세요.

---

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 타입 검사 + 프로덕션 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run sanity` | 계산값 검증 스크립트 (콘솔 출력) — 검증 표 작성용 |

- 모든 계산은 **브라우저 안에서** 수행됩니다. 서버도, 유료 API 도 사용하지 않습니다.
- 16:9 노트북·프로젝터 화면을 기준으로 만들었습니다. 1280×720 이상을 권장합니다.

## 무엇을 하는 프로그램인가

삼풍백화점 붕괴 조사에서 확인된 주요 구조 변수를 이용해,
**"구조가 어떻게 달랐다면 펀칭전단과 연쇄붕괴의 위험을 줄일 수 있었는가"** 를
교육적으로 시각화합니다.

전체 건물을 재현하지 않고, 플랫슬래브의 **2×2 bay 일부와 중앙 기둥 하나**만 다룹니다.

## 화면 구성

### 탭 1 — 구조 시뮬레이션

3열 구성입니다. 화면 가장 넓은 가운데를 3D 구조가 차지합니다.

- **가운데(가장 큼)** : 3D 구조 (RC 슬래브, 원형 기둥, 슬래브-기둥 접합부, 드롭패널, 상부 철근,
  하중 화살표). 조작 버튼은 3D 화면 아래쪽 중앙에 떠 있는 툴바로 모았습니다.
- **왼쪽** : 변수 조절 슬라이더
- **오른쪽** : 시나리오 설명 + Vu / φVn / D/C 실시간 표시 + 숫자를 대입한 계산 과정 8줄 +
  변수 변경이 요구(Vu)와 저항(φVn) 중 무엇을 움직였는지에 대한 한국어 설명
- **아래** : 시나리오 비교 (접이식 서랍 — 기본은 접혀 있어 3D 가 최대 크기를 씁니다)
- **위** : 프리셋 3개 — `삼풍 단순화 조건` / `구조계산 조건` / `안전 개선 설계`
  (버튼을 눌러도 **카메라 각도가 유지**되어 같은 시점에서 비교할 수 있습니다)

**3D 화면에서 볼 수 있는 것**

- D/C 가 커질수록 기둥 주변에 **원형·방사형 균열**이 늘어나고 진해집니다.
- `펀칭전단 붕괴 재생` 을 누르면 기둥이 슬래브를 뚫는 **펀칭전단 파괴**와, 이어서 하중이
  재분배되며 인접부가 시간차를 두고 무너지는 **연쇄붕괴 개념**이 재생됩니다.
- 시점 버튼 : `전체 보기` / `접합부 확대` / `측면(단면) 보기`
  — 접합부 확대로 보면 균열과 상부 철근이 잘 보입니다.

### 탭 2 — 붕괴 회피 실험

"어떻게 하면 무너지지 않을 수 있었는가"를 직접 실험하는 탭입니다. 세 가지 실험 모두 시뮬레이션
탭과 **같은 펀칭전단 식**을 조건만 바꿔 반복 계산한 것입니다.

1. **2×2 요인 실험** — 시공 조건(실제 / 구조계산서) × 하중 조건(실제 / 원설계)
2. **누적 개선 경로** — 지적된 항목을 하나씩 되돌릴 때 D/C 가 언제 1.0 아래로 내려가는가
3. **임계값 탐색** — 변수 하나만으로 목표 D/C 를 만들려면 얼마가 필요한가 (이분법)

기본 설정에서의 2×2 결과 (사용하중 기준, 교육용 값):

| | 하중 : 실제 사용 | 하중 : 원설계 |
|---|---|---|
| **시공 : 실제** | **1.28** (파괴 위험) | 0.93 |
| **시공 : 구조계산서** | 0.91 | 0.67 |

네 칸 중 한 칸만 1.0 을 넘습니다. 즉 이 모형 안에서는 **시공과 사용 중 어느 한쪽만 원래
계획대로였어도 이 접합부의 D/C 는 1.0 아래였다**는 결과가 나옵니다. 다만 접합부 하나에 대한
단순화 계산이므로 실제 사건의 원인을 확정하는 근거가 될 수 없습니다.

### 탭 3 — 탐구 모드 (One Variable at a Time)

기준 모델(Scenario A)에서 변수를 **한 번에 하나씩만** 바꾸어 D/C 변화를 비교합니다.
마지막에는 모든 개선안을 동시에 적용한 결과도 함께 보여 줍니다.
`Export Result as PNG` 로 PPT 에 넣을 이미지를 저장할 수 있습니다.

### 탭 4 — 역사적 배경

일제강점기 근대 건축기술 도입부터 1995년 이후 건설안전 제도 강화까지의 타임라인입니다.
**역사 정보는 구조 계산 코드와 완전히 분리되어 있으며**(`src/data/history.ts`),
계산에 전혀 사용되지 않습니다.

### 탭 5 — 방법 · 한계

화면에서 바로 볼 수 있는 방법론·한계 요약입니다.

## 조절할 수 있는 변수

| 변수 | 범위 |
|---|---|
| 기둥 직경 | 500 ~ 1000 mm |
| 콘크리트 압축강도 f'c | 15 ~ 40 MPa |
| 기둥부 유효깊이 d₁ | 300 ~ 500 mm |
| 상부 인장철근비 / 기둥 주철근 개수 | 0.2 ~ 2.0 % / 4 ~ 32 (HD22) |
| 고정하중 (마감·설비) | 0 ~ 10 kPa |
| 활하중 | 0 ~ 12 kPa |
| 국부 추가하중 | 0 ~ 12 kPa |
| 드롭패널 유무 / 크기 / 두께 | 1500 ~ 5000 mm / 0 ~ 250 mm |
| 펀칭전단 보강 유무 / 보강량 | 0 ~ 1 |
| 용도 | 판매장 / 식당가 / 사무실 / 창고 |
| (추가) 경간, 지지 층수, 기준식, 하중조합, 크기효과계수, 모멘트 할증 | — |

용도를 바꾸면 그 용도의 대표 고정하중·활하중이 자동으로 적용되고,
**용도 변경이 하중을 얼마나 바꾸는지** 화면에 표시됩니다.

## 세 프리셋

| | A. 삼풍 단순화 조건 | B. 구조계산 조건 | C. 안전 개선 설계 |
|---|---|---|---|
| 기둥 직경 | 600 mm | 800 mm | 900 mm |
| 기둥 주철근 | 8-HD22 | 16-HD22 | 20-HD22 |
| 콘크리트 강도 | 18.4 MPa | 21 MPa | 30 MPa |
| 기둥부 유효깊이 | 360 mm | 410 mm | 500 mm |
| 구조형식 | 무량판(드롭패널 없음) | 무량판(드롭패널 없음) | 드롭패널 신설 3600×150 mm |
| 전단보강 | 없음 | 없음 | 있음 (0.80) |
| 용도 / 국부 추가하중 | 식당가 / 3.0 kPa | 판매장 / 없음 | 판매장 / 없음 |

기본 설정에서의 결과(교육용 값):

| | A | B | C |
|---|---|---|---|
| D/C (설계 1.2D+1.6L, φ=0.75) | **2.19** | **1.18** | **0.47** |
| D/C (사용 1.0D+1.0L, φ=1.0) | 1.28 | 0.67 | 0.27 |

> A 와 B 는 기둥머리 드롭패널이 없는 **무량판(플랫플레이트)** 으로 모델링했습니다.
> (자료가 서로 다르게 말하는 부분이라 `source-notes.md` 2.3절에 그대로 기록해 두었습니다.)
> A 와 B 의 기둥·재료 조건은 과제에서 제시된 조사자료 값이지만,
> **경간과 하중은 확인하지 못해 교육용 가정값**입니다.
> 이 숫자를 사실로 인용하지 말고, 상대적인 차이를 읽는 데 사용하세요.

## 결과 판정 기준

| D/C | 표시 |
|---|---|
| 0.0 ~ 0.7 | 상대적으로 낮음 |
| 0.7 ~ 1.0 | 주의 |
| 1.0 이상 | 파괴 위험 |

**이 구분 역시 교육용입니다.** 실제 안전 판정 기준이 아닙니다.

## PNG 저장 (PPT용)

- 시뮬레이션 탭 : 오른쪽 위 `Export Result as PNG` — 3D 화면 + 비교표를 함께 저장
- 탐구 모드 탭 : `Export Result as PNG` — 그래프 + 결과표 + 설명 저장
- 역사적 배경 탭 : `Export as PNG` — 타임라인 저장

버튼 자신은 저장 이미지에서 제외됩니다.

## URL 옵션 (발표 자료·화면 녹화용)

```
?tab=sim|solve|ovat|history|docs   시작할 탭
?preset=A|B|C      시작할 프리셋
?view=overview|joint|section   시작 시점
?collapse=1        붕괴 애니메이션 자동 재생
?compare=1         하단 시나리오 비교 서랍을 펼친 상태로 시작
```

예 : `http://localhost:5173/?preset=A&view=section&collapse=1`

## 폴더 구조

```
src/
  model/          구조 계산 (역사 정보와 완전히 분리)
    types.ts        변수 정의, 범위, 용도별 하중
    punching.ts     펀칭전단 demand/capacity 계산 (ACI 318-19 / EC2)
    presets.ts      세 시나리오
    ovat.ts         One Variable at a Time 실험 정의
    explain.ts      변수 변경에 대한 한국어 설명 생성
  data/
    history.ts      역사 타임라인 (계산에 사용되지 않음)
  components/
    Scene3D.tsx     3D 시각화 + 균열/붕괴 애니메이션
    ControlPanel.tsx / ResultPanel.tsx / CompareSection.tsx
    OvatTab.tsx / HistoryTab.tsx / DocsTab.tsx / ui.tsx
  lib/exportPng.ts  PNG 저장
scripts/
  sanity-check.ts   계산값 검증 스크립트
```
